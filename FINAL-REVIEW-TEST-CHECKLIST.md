# Rent Master — Final Review and UI Checklist

## Tenancy and reviews

- [ ] Review action is unavailable before the tenancy is completed.
- [ ] Closure must be requested by one party and approved by the other.
- [ ] Owner must record final handover before reviews are enabled.
- [ ] Owner can publish only one review for that tenancy.
- [ ] Tenant can publish only one review for that tenancy.
- [ ] A submitted review appears immediately on the reviewed user's reputation profile.
- [ ] A submitted review immediately affects the average and distribution.
- [ ] Reviewed person can report the review with a required reason.
- [ ] Reporting does not automatically remove the review.
- [ ] Report appears in Admin → Reported reviews.
- [ ] Admin must enter a decision note.
- [ ] Keep review leaves it visible and included in the rating.
- [ ] Remove review hides it and recalculates the public rating.

## Reputation page

- [ ] “My profile” loads the current account even if an old profile code was stored in the browser.
- [ ] Unknown code shows only “Profile not found”.
- [ ] Connection or server failure shows only one useful error message.
- [ ] Fractional rating stars, category averages and distribution are correct.
- [ ] Only the reviewed person sees “Report an issue”.

## Help & Support and layout

- [ ] Help page has a clear header and balanced spacing.
- [ ] Form fields and Send request button are fully visible.
- [ ] Validation messages are readable.
- [ ] Support history fits correctly on desktop, tablet and mobile.
- [ ] Footer stays at the bottom on short pages.
- [ ] Long pages scroll normally.
- [ ] © 2026 AvioInfotech. All rights reserved. is visible.

## Existing requested features

- [ ] Owner can attach 1–10 photos when creating or editing a property.
- [ ] Property cannot be published without at least one photo.
- [ ] Photos appear in search, property details and owner listings.
- [ ] Authorised Admin can see the complete Aadhaar or passport number.
- [ ] Other owners and tenants cannot see another user's identity number or document.
- [ ] Admin can switch between waiting identity submissions and verified users.
- [ ] Verified-user search works by name, email, phone, profile code and document number.
